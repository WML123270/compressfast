## First Comment（创始人开场白）

Hi Product Hunt! 👋

I built CompressFast because I was tired of uploading client design files to cloud tools just to shrink them. TinyPNG needs upload, Squoosh can't batch, everything else wants a subscription. So I made the tool I wanted:

🛡️ **100% local** — open DevTools Network panel, zero image data ever leaves your browser. Disconnect your internet, it still works.

🎯 **AVIF output** — 50% smaller than JPEG at same quality. Few online tools support AVIF encoding.

💰 **$24.99 lifetime** — not a subscription. Buy once, own it forever.

⚡ **30 images free per batch**, 500 for Pro. Drag-to-reorder, bulk ZIP download, Ctrl+V paste. Resize, rotate, strip EXIF — all in the browser.

Everything runs on Canvas API + Web Workers + WASM in the browser sandbox. No servers touch your images.

Would love your feedback — especially on the AVIF output quality!
