**正文草稿**:

```
平时做前端项目经常要压缩图片，TinyPNG 虽然好用但每次都要上传到对方服务器，
公司内部项目的图就不太方便。周末花了些时间自己写了一个，分享出来。

## 特点

1. 纯本地处理 — 压缩全程在浏览器里完成，断网也能用，F12 网络面板无图片外发
2. 批量压缩 — 单次 100 张，一键 ZIP 下载
3. 三种预设 — 最大压缩 / 均衡 / 最佳画质，支持手动调节
4. 指定大小压缩 — 设定目标 KB，自动逼近
5. 6 种格式 — PNG / JPEG / WebP / GIF / BMP / SVG
6. 格式互转 — 输出可选 PNG / JPEG / WebP
7. Ctrl+V 粘贴 — 截图直接粘贴压缩
8. 暗色模式 + PWA — 可安装到桌面

## 对比页

https://jisuyatu.com/vs-tinypng

## 技术栈

Next.js 14 + Canvas 压缩 + Web Worker + Zustand + TailwindCSS

## 链接

🔗 https://jisuyatu.com

代码暂未开源，整理好了放 GitHub。欢迎试用和反馈 🙏
```
