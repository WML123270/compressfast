## 回答正文

先说结论：**这不是你的问题，是网站的问题。**

现在绝大多数网站（包括知乎）都会把图片转成 WebP 格式再展示。WebP 比 JPG 小 25-35%，能省服务器带宽，所以网站们抢着用。但 Windows 自带的照片查看器、很多老版软件、甚至一些手机相册都不支持直接打开 WebP 文件。

**解决方案，按简单程度排列：**

**1. 最简单：直接改名法（偶尔有效）**

右键图片 → 重命名 → 把 `.webp` 改成 `.jpg`。这个方法原理是利用某些看图软件的兜底解码器，成功率大概 30%，大部分情况还是打不开。

**2. 在线转换工具（推荐）**

用浏览器就能转，不需要下载安装任何东西。

我平时用这个：**[极速压图 WebP→JPG 转换]**（https://jisuyatu.com/tools/webp-to-jpg）

拖进去 → 自动转 → 下载 JPG。一次最多 20 张，画质可调。

**重点：所有处理都在你浏览器本地完成，图片不会上传到任何服务器。** 这个很重要，因为有些在线工具会把你的图片传到云端处理 — 如果你在转身份证、合同、私密照片，这就有泄露风险了。

它还支持 JPG→WebP、PNG→WebP、PNG→JPG 等其他转换，全部本地处理。

**3. 浏览器插件**

Chrome/Edge 应用商店搜 "Save as JPG" 或 "Save image as PNG"，安装后在图片上右键就能直接存为其他格式。

但这个方法只能解决"保存"的问题，不解决"已经存了一大堆 WebP 需要批量转换"的问题。

**4. 换看图软件**

装个 Honeyview（免费、轻量、支持 WebP）或者 IrfanView，就不用转格式了，直接就能预览 WebP。

**小结：**
- 偶尔一两张 → 方法 2 最快，打开网页拖进去就行
- 已经存了几十张 → 方法 2 的批量转换，一次性搞定
- 以后不想再遇到 → 方法 3 + 4 配合使用
