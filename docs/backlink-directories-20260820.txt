【长描述】（200-400 字，大多数站要填这个）
  CompressFast is a browser-based image compressor that processes files
  entirely on-device — nothing is ever uploaded to a server. It supports
  PNG, JPEG, WebP, AVIF, GIF, BMP, SVG and HEIC, batches up to 30 images
  at once, resizes and converts between formats, strips EXIF metadata,
  and downloads everything as a ZIP. Built with Canvas API and Web Workers,
  it runs offline as a PWA and costs $0/month to operate.
