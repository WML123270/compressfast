**标题**: [分享创造] 极速压图 — 纯本地图片压缩工具，文件绝不上传

**正文**:

之前一直用 TinyPNG 压图，但公司项目的设计稿不太方便往别人服务器传。周末写了个工具自己用，打磨了两个月，现在分享出来。

## 核心亮点

**1. 纯本地处理，绝对隐私**
压缩全程在浏览器里完成，文件不会上传到任何服务器。断网也能正常用，打开 F12 网络面板看——零图片数据外发。

**2. 功能齐全**
- 📦 单次 30 张批量压缩，一键 ZIP 下载
- 🎨 7 种输入格式（PNG/JPEG/WebP/GIF/BMP/SVG/HEIC）
- 🔧 画质/速度自由调节 + 目标文件大小模式 + 无损压缩
- 📐 尺寸调整（像素 + 百分比 + 预设 1080p/720p）
- 💧 文字/图片水印，九宫格定位
- 🔄 旋转/翻转 + 拖拽排序
- 🛡️ EXIF 隐私清除（GPS/相机信息一键抹掉）
- 🌙 暗色模式 + PWA（可装桌面当本地应用）
- 📋 Ctrl+V 粘贴截图直接压

**3. 完全免费**
国内版所有功能免费，无广告，不限制使用次数。
