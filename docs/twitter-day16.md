## Thread

**2/5 — The WebP problem is real.**

You download an image from a website → can't open it → turns out it's WebP.

Windows Photos doesn't support it. Older apps can't read it.

I added webp-to-jpg and webp-to-png to fix this exact pain point. Drag → convert → done.

**3/5 — Sometimes you need the opposite.**

PNG is great for transparency, but 5MB for a screenshot is too much.

jpg-to-webp / png-to-webp: same visual quality, 25-35% smaller files.

png-to-jpg: transparent PNGs get a white background. Ideal for websites & email attachments.

**4/5 — SVG → PNG at any resolution.**

Need a 4K raster version of an SVG icon? Just set the width and hit convert.

Perfect for app icons, presentation graphics, or print-ready exports.
